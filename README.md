# 地毯工作台 · Windows 桌面版

支持 Windows 10 / 11 的 64 位电脑，无需安装 Node.js 或启动服务器。

v1.6.1 延续 1.5.0 的 Linear 风格和布局：固定文字侧栏、两列材质卡片、清晰的报价表格、极细描边和局部暖橙柔光。材质名称前增加绿色、黄色、浅蓝等彩色小圆点，卡片按 1–9 顺序排列，最后一款靠左；卡片适当降低高度，让名称与单价更舒展。正文、材质名称、导航和报价明细保留放大后的字号，左上角图标居中对齐。提供页面切换淡入、材质选择反馈和 React Bits 报价卡片柔光，系统开启“减少动画”时自动停用。提供炭黑夜间与雾白日间两套主题，默认以日间主题打开，点击左下角“日间 / 夜间”切换，重启后保留选择。内置 Manrope 与 Noto Sans SC 字体，材质选择保持纯文字，价格统一使用暖橙色。尺寸输入框可拖动调整高度。价格表、价格与重量配置、图片编辑工具和更新面板均使用统一样式。常规操作没有提示弹窗；下载并校验完成的新版本会询问是否安装，错误直接显示在页面内。

`release` 文件夹包含：

- `地毯工作台.exe`：免安装版，双击运行。
- `地毯工作台-安装版.exe`：安装版，可选择安装位置并创建桌面快捷方式。
- `prices.json`：免安装版使用的价格配置，与 exe 放在同一文件夹。

页面标题上方保留 100 条随机文案，每次打开更换一条，一轮内不重复。右上角显示今日天气的城市、天气状况和温度，并保留刷新按钮。桌面版先直连查询本机公网 IP，再明确查询该 IP 的归属城市与坐标，避免沿用天气请求的代理出口位置。IP 库不一定能精确到区县；天气每 15 分钟更新。旧版定位缓存升级后不再使用。天气需要联网；断网时最多使用两小时内的缓存并标记“上次更新”，没有可用缓存时显示“暂不可用”，不影响本地报价。

报价明细增加“单价”列：定制尺寸显示实际采用的元/㎡单价（包括临时价、窄幅价），现成规格显示元/张单价。

输入有效尺寸后会自动复制报价。单张格式为 `100*100的价格是40元`：现成尺寸保留小数（如 `60*90的价格是18.8元`），定制尺寸金额舍去小数。多张时每个尺寸一行，金额统一保留两位小数，再加张数和取整总价；例如 `124*240 = 119.04元`、`120*120 = 57.60元`、`两张`、`总价格176元`。总价先汇总所有实际金额，再舍去小数。点击“复制所有尺寸价格”或按 Insert 时，每个尺寸及价格一行，多张末尾加精确总价，不加张数；所有金额保留小数。输入为空或存在无效尺寸时，不会覆盖剪贴板。

在报价页可用主键盘或小键盘的数字键 1–9 按编号选择材质：1 条纹、2 菱形方格、3 硬丝、4 平面、5 流星毯、6 丝圈、7 宽条纹、8 硅藻泥、9 菠萝纹。卡片角落标有快捷键。输入尺寸、单价或搜索文字时，数字键照常输入；其他页面及 Ctrl、Alt、Shift 组合键不切换材质。切换材质后，已有尺寸会重新报价并按原规则自动复制。

## 修改价格

配置包含条纹、菱形方格、硬丝、平面、流星毯、丝圈、宽条纹、硅藻泥、菠萝纹九种材质，编号依次为 1–9。菠萝纹默认单价为 60 元/㎡，可在“价格配置”修改；没有预设现成规格价格和每平重量。升级后会自动补上菠萝纹，保留已有价格、重量和现成规格；添加前的配置备份为 `prices.json.before-1.4.5.bak`。旧编号及方格款式重量的迁移继续保留。

进入软件左侧的“价格配置”，可直接修改材质单价、最大宽度、窄幅单价、现成规格价格，以及“每平重量”（kg/㎡，标准款和方格款式分别修改），点击“保存配置”立即生效，计算器与尺寸价格表同步更新。

也可以点击“打开配置文件”，使用记事本编辑 JSON，保存后回到软件点击“重新加载”。配置字段均为中文：

```json
{
  "编号": "8",
  "名称": "硅藻泥",
  "单价": 50,
  "支持定制": true,
  "最大宽度": 160
}
```

`单位重量`使用 kg/㎡，例如 `"单位重量": 2.75`；有方格款式时使用 `"单位重量": { "标准": 2.4, "方格款式": 3.6 }`。旧配置中的“加厚”重量会自动改名为“方格款式”，保留原数值。未设置的材质不计算重量，可在配置页填写；普通款清空重量并保存可取消重量计算。

以上是单个产品的示例，编辑时保留文件中的其他产品和配置字段。`单价`单位为元 / ㎡；`现成尺寸价格`中的`价格`单位为元 / 张。数字不加引号。

计价顺序：临时单价优先，其次是启用的现成规格价格，再是窄幅规则，最后使用材质单价。修改材质单价不会改动已有的现成规格价格；需要时可在报价区关闭“现成价格优先”。

宽度只取输入的第一个数字。硅藻泥只有宽度 **大于 160 厘米** 才提示拼接：`100*160`、`160*100`不提示，`161*100`提示。选择材质时不显示限宽提示。

保存配置前会备份到 `prices.json.bak`。配置格式或金额错误时，会显示原因并保留当前有效价格，不覆盖出错的文件。

免安装版优先使用 exe 同文件夹中的 `prices.json`；该文件夹不可写时，或使用安装版时，配置保存在 `%APPDATA%\CarpetStudio\prices.json`。软件的“价格配置”页面会显示实际位置。

## 其他功能

新版优先加载报价页，图片工具、价格表和配置页首次打开时再加载，并保留已打开页面的内容。尺寸输入只更新报价区域；超过 80 组尺寸时，明细可滚动查看，计算和复制始终包含全部尺寸。输入停顿约 180 毫秒后自动复制。免安装版采用更快的解压方式，安装版打开时无需重复解压。

多行尺寸和数量计算、现成规格计价、多产品汇总、重量参考、尺寸价格筛选，以及六种内置图片的尺寸标记、拖动、剪贴板复制和 PNG 保存。报价与图片编辑均在本地完成。

## 检查更新与 GitHub 发布

下载新版时自动通过 `https://ghfast.top/` 加速，链接格式为 `https://ghfast.top/https://github.com/Fy-MoMing/DiTangongzuotai/releases/download/实际版本号/实际文件名`，保留仓库、版本号及免安装版或安装版文件名。检查更新和“GitHub 发布页”继续使用原地址。

左下角显示当前完整版本号和“检查更新”按钮，点击可打开“软件更新”。支持手动检查、启动后后台检查与每 15 分钟定期检查。有新版时，软件通过国内加速地址自动下载对应的安装版或免安装版，并核对 SHA-256 校验值，显示下载进度。下载或校验失败时可重试；已校验的缓存文件会复用。下载完成后才出现“立即更新 / 稍后再说”窗口，点击“稍后再说”可以继续报价，本次打开不重复打扰。

只有点击“立即更新”才退出软件并启动更新：安装版打开新版安装程序；免安装版等待旧进程退出、替换原 exe 后重新打开。现有价格配置保持原位置。检查失败在面板内显示，不影响本地功能。1.5.0 及更早版本仍使用旧的浏览器下载流程，需先手动升级到 1.6.0；后台下载及确认安装从 1.6.0 开始生效。

GitHub 下载项显示中文名称，文件名分别为 `DiTan-Portable.exe`（免安装版）和 `DiTan-Setup.exe`（安装版），用于稳定匹配更新。

更新源为 https://github.com/Fy-MoMing/DiTangongzuotai ，在 `config/github.json` 配置。检查优先使用本机直连，请求失败或遇到限流时再尝试系统网络。程序只检查 GitHub Releases 的公开正式版本，版本标签使用 `v主版本.次版本.修订版本`，例如 `v1.4.0`，不提示降级或测试版。断网可正常使用本地功能。

后续发版：修改根目录 `package.json` 和 `package-lock.json` 的版本，提交后推送对应版本标签，例如 `git tag v1.4.1`、`git push origin v1.4.1`。GitHub Actions 会测试、构建 Windows 免安装版和安装版，并发布到 Releases；左下角版本号随打包版本自动变化。1.4.4 及以后版本支持检查更新，旧版需先手动升级一次。

## 开发与打包

安装 Node.js 22.12 或更新版本，在项目根目录运行：

```powershell
npm install
npm start
```

默认价格模板位于 `config/prices.json`。生成新 exe：

```powershell
npm run dist
```

验证计价逻辑和桌面功能：

```powershell
npm run test:pricing
npm run pack
npm run test:desktop
```

当前构建没有配置数字签名证书，Windows 可能显示未知发布者提示。
